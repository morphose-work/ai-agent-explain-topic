# 🤖 AI Agent for Explain Topics

ИИ-агент, который объясняет сложные темы простым языком.

## 🛠 Стек
- Python 3.10+
- CrewAI (агенты)
- Streamlit (интерфейс)
- OpenRouter (бесплатные LLM модели)
- DuckDuckGo (поиск)

## 🚀 Как запустить

1. Клонируй репозиторий:
   git clone https://github.com/morphose-work/ai-agent-explain-topic

2. Установи зависимости:
   pip install -r requirements.txt

3. Создай файл .env:
   OPENROUTER_API_KEY=твой_ключ

4. Запусти:
   streamlit run main.py
